# Bilibili 系列字幕导出

Chrome / Edge Manifest V3 本地扩展。它优先导出 Bilibili 已有字幕；遇到无字幕、字幕为空或明显错配的普通公开视频时，可使用免费的本机 Whisper `tiny`、`base` 或 `small` 补齐。

当前版本：`1.3.0`

扩展侧栏采用与 Pond 星空图标和 `WHISPER LIVE` 一致的深空蓝、星云紫与冰青仪表风格，操作卡、选择器、确认区、运行进度和失败清单使用统一的视觉层级。

> **使用声明：** 本项目仅限个人学习及处理本人有权访问的公开视频。请遵守 [Bilibili 用户使用协议](https://www.bilibili.com/blackboard/user-rule-linux.html?night=1&padding=0) 和相关版权规定，不得用于未经授权的批量抓取、传播或商业用途。本项目不绕过登录、付费或其他访问控制。

## 安装前先选一种方式

> **仅B站字幕无需Python。** 只要视频已经有 B站字幕，加载扩展后即可使用，不要运行 `install-helper.ps1`。
>
> **Whisper补齐需要安装助手。** 只有需要转写无字幕分P时才安装；如果不需要即可不安装，不影响 B站已有字幕的导出。

### 路径一：仅B站字幕，无需Python

1. 在 GitHub 仓库点击 `Code` → `Download ZIP`，然后解压并保留文件夹内部结构。
2. 按下面对应浏览器的步骤加载解压后的整个文件夹。
3. 打开普通 Bilibili 视频页即可使用。扫描到无字幕分P时选择“仅导出B站字幕”。

Chrome：

1. 打开 `chrome://extensions/`；
2. 开启“开发者模式”；
3. 点击“加载已解压的扩展程序”；
4. 选择解压后包含 `manifest.json` 的文件夹。

Edge：

1. 打开 `edge://extensions/`；
2. 开启“开发人员模式”；
3. 点击“加载解压缩的扩展”；
4. 选择解压后包含 `manifest.json` 的文件夹。

这条路径不会安装 Python、Whisper 模型或后台助手。面板提示“本机助手不可用”是正常现象，仍可导出全部已有 B站字幕。

### 路径二：Whisper补齐，需要安装助手

先按“路径一”加载扩展。然后准备 Windows 10/11、64 位 Python 3.10 或更高版本、至少 5GB 可用磁盘空间，以及首次下载依赖和默认 Whisper `small` 模型的网络连接。

在解压后的文件夹空白处按住 Shift 单击鼠标右键，打开 PowerShell，然后运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\install-helper.ps1
```

脚本会自动：

1. 在 `%LOCALAPPDATA%\BiliSubtitleWhisper` 创建独立 Python 环境；
2. 安装固定版本的 `faster-whisper 1.2.1` 和 `yt-dlp 2026.7.4`；
3. 免费下载默认 Whisper `small` 模型；`tiny` 和 `base` 会在首次选择时自动下载；
4. 生成随机安装令牌，并分别写入本机助手配置和当前扩展目录中被 Git 忽略的 `helper-token.js`；
5. 注册当前 Windows 用户登录后静默启动；
6. 启动并检查本机助手。

安装完成后，请回到扩展管理页点击“重新加载”。扩展会从当前目录读取本机生成的随机令牌，不需要手工复制。助手只验证令牌，不依赖 Chrome/Edge 扩展 ID；同一目录移位或作为临时副本加载时不会因为扩展 ID 改变而失效。依赖默认从 PyPI 获取；连接异常时安装脚本会自动使用阿里云 PyPI 公共镜像重试，该镜像不参与字幕转写。

## 分享包内容与隐私

GitHub 仓库仅包含扩展运行源码、浏览器需要的 PNG 图标、本机助手源码、固定依赖清单、安装/卸载脚本、自动测试、许可证和本说明。

分享包不会包含 `.git`、日志、缓存、Python 字节码、令牌、模型、音频、任务数据、字幕或导出的 Markdown。安装后生成的个人数据只位于 `%LOCALAPPDATA%\BiliSubtitleWhisper`，不会写回分享文件夹。

- 不使用任何付费 API、订阅服务、API 密钥或云端转写。
- 音频和字幕不会上传到 AI 服务。
- 本机助手只监听 `127.0.0.1:17891`，并使用随机安装令牌验证，不依赖 Chrome/Edge 扩展 ID。
- `helper-token.js` 仅由安装脚本在用户电脑上生成，已被 Git 忽略，不会进入 GitHub 分享内容。
- 不读取浏览器 Cookie，不绕过登录、付费或地区限制；只让 `yt-dlp` 下载公开普通视频的音频。
- 每次只处理一个分P，转写完成后立即删除临时音频。

## 使用

1. 打开普通 Bilibili 视频页。
2. 在右侧面板选择“当前分集”“本视频全部分P”“选择分P批量导出”或“整个合集”。
3. 扩展先逐集扫描 B站字幕，并分别统计：
   - B站字幕可用；
   - 需要本机补齐：没有字幕、字幕为空、字幕明显错配；
   - 暂不可处理：需要登录、无权访问、网络或接口失败。
4. 若存在可补齐分P，确认数量和音频总时长，选择 Whisper 模型后点击“免费本机补齐”。也可选择“仅导出B站字幕”。模型选择会保存在浏览器中，下次继续使用。
5. 完成后点击“下载 Markdown”。

处理完成后，面板会自动展开“未成功导出的分P”，显示 P号、标题和失败原因；点击其中一项可打开对应分P。点击“只重试失败项”仅重新处理失败分P，当前页面内已成功的字幕直接复用，不会重新扫描全部分P。

分P批量导出仍支持：

- 合并为一个 Markdown；
- 每个分P一个 Markdown；
- 合并自然段；
- 保留可点击时间戳。

Markdown 会注明每集来源：“B站人工字幕”“B站AI字幕”或实际使用的“本机 Whisper tiny/base/small”。

## 本机转写行为

- 可选 multilingual Whisper `tiny`（最快）、`base`（平衡）和 `small`（更准确、较慢），默认 `small`，语言固定为中文；`onnxruntime` 可用时开启 VAD，若 Windows 运行库导致它无法加载则自动关闭 VAD 并继续转写。
- 任务开始后会锁定所选模型。队列串行运行，同一时间只保留一个模型实例，切换模型时先释放旧模型以控制内存。
- 自动加入 Python、PyCharm、NumPy、Pandas 等课程术语提示。
- 检测到可用 NVIDIA CUDA 时优先使用 GPU；加载失败会自动回退到 CPU `int8`。
- 不进行 AI 纠错、摘要、改写或内容合并；“合并自然段”仅改变 Markdown 排版。
- 面板的 Whisper 实时状态卡会显示实际模型、当前 P号和标题、下载音频/加载模型/识别字幕阶段、CPU 或 GPU、当前阶段百分比、已用时间、整体进度；完成首个分P后动态估算剩余时间。识别百分比按已完成的字幕片段更新，可能从一个数值跳到另一个数值，这是实际进度而非卡顿。
- 页面、浏览器或电脑关闭后，任务保存在本机；重新打开相同 BV 页面会恢复进度或结果。
- 本机失败会在 Markdown 末尾列出原因，不会切换到付费服务。

## 取消、缓存与卸载

- 面板中点击“取消”会通知本机队列停止；当前下载或识别步骤可能需要一点时间才响应。
- 已完成分P保存在 `%LOCALAPPDATA%\BiliSubtitleWhisper\results`，缓存按 `bvid:cid:model` 隔离；同一视频使用不同模型不会混用字幕，相同模型再次处理会直接复用缓存。
- 卸载本机助手及其模型、任务和缓存：

```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall-helper.ps1
```

卸载脚本会移除本机运行目录和当前用户启动项，不会删除“扩展”项目文件夹。

## 故障排查

- **提示助手未安装、令牌缺失或无法连接**：在当前扩展目录重新运行 `install-helper.ps1`，然后重新加载扩展。
- **模型下载失败**：安装时只预下载默认 `small`；首次选择 `tiny` 或 `base` 会从 ModelScope 的 Systran 官方镜像自动下载，并支持断点续传。失败时检查网络和磁盘空间后重试，完整文件会复用，`model.bin` 大小不符时不会加载。
- **提示助手版本过旧或不支持所选模型**：重新运行 `install-helper.ps1`，再到扩展管理页点击“重新加载”；扩展不会静默改用其他模型。
- **公开音频下载失败**：Bilibili 或 `yt-dlp` 解析可能发生变化；更新项目版本后重试。登录或付费内容不会使用 Cookie 绕过限制。
- **CPU 转写较慢**：这是免费的本机计算；可保持助手后台运行，之后回到同一个 BV 页面恢复。
- **显示需要登录或无权访问**：先在网页确认自己有权观看并刷新。此类失败不会自动进入 Whisper 队列。
- **日志位置**：`%LOCALAPPDATA%\BiliSubtitleWhisper\logs\helper.log`。
