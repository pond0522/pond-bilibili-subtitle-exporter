# 🎬 Bilibili 系列字幕导出

一个 Chrome / Edge 本地扩展，帮你把 B 站视频字幕整理成 Markdown 文档。

扩展会优先使用 B 站已有字幕；遇到没有字幕、字幕为空或明显错配的普通公开视频时，也可以选择免费的本机 Whisper `tiny`、`base` 或 `small` 补齐。

当前版本：`1.3.1`

> [!WARNING]
> **使用声明：** 本项目仅限个人学习及处理本人有权访问的公开视频。请遵守 [Bilibili 用户使用协议](https://www.bilibili.com/blackboard/user-rule-linux.html?night=1&padding=0) 和相关版权规定，不得用于未经授权的批量抓取、传播或商业用途。本项目不绕过登录、付费或其他访问控制。

## 🚦 先选一种使用方式

| 你想做什么 | 需要 Python 吗 | 选择 |
| --- | --- | --- |
| 只导出 B 站视频本身已有的字幕 | 不需要 | [路径一](#-路径一只导出-b-站字幕不用装-python) |
| 用 Whisper 补齐没有字幕的视频 | 需要 | [路径二](#-路径二用-whisper-补齐没有字幕的视频) |

> [!TIP]
> 本机 Whisper 助手完全可选。只使用 B 站已有字幕时，不要运行 `install-helper.ps1`；即使面板提示“本机助手不可用”，也不影响已有字幕的正常导出。

## ✨ 这个扩展能帮你做什么

- 导出 B 站人工字幕和 AI 字幕。
- 批量处理一个视频的多个分P，也可以处理当前视频所属的合集。
- 将结果合并为一个 Markdown，或让每个分P单独保存。
- 默认将连续字幕合并成更适合阅读的自然段；只调整排版，不纠错、不摘要、不改写内容。
- 每条字幕或合并后的段落都带有可点击的时间戳，方便返回原视频对应位置。
- 没有字幕时，可在本机免费运行 Whisper 转写，不需要 API 密钥，也不会产生云端转写费用。
- 检测到可用的 NVIDIA CUDA 时自动使用 GPU；不可用或加载失败时自动改用 CPU。
- 本机任务和已完成字幕可以恢复，关闭页面或浏览器后不必从头开始。

## 🟢 路径一：只导出 B 站字幕（不用装 Python）

1. 点击仓库上方的 `Code` → `Download ZIP`。
2. 解压下载的文件，并保持文件夹内部结构不变。
3. 按下面对应浏览器的步骤，加载包含 `manifest.json` 的整个文件夹。

### Chrome

1. 打开 `chrome://extensions/`。
2. 开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择解压后包含 `manifest.json` 的文件夹。

### Edge

1. 打开 `edge://extensions/`。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择解压后包含 `manifest.json` 的文件夹。

安装完成后，打开普通 B 站视频页即可使用。扫描到没有字幕的分P时，可以选择“仅导出B站字幕”。

这条路径不会安装 Python、Whisper 模型或后台助手。如果只使用已有字幕，面板提示“本机助手不可用”时可以直接忽略。

## 🧠 路径二：用 Whisper 补齐没有字幕的视频

先按“路径一”加载扩展，然后准备：

- Windows 10/11；
- **64 位 Python 3.10–3.12**，当前依赖暂不支持 Python 3.13/3.14；
- 至少 5GB 可用磁盘空间；
- 首次安装依赖、下载模型和获取公开视频音频所需的网络连接。

在解压后的文件夹空白处按住 `Shift`，单击鼠标右键并打开 PowerShell，然后运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\install-helper.ps1
```

默认会下载并验证 `tiny`、`base`、`small` 三个模型。

<details>
<summary><strong>只下载部分模型，或稍后再下载</strong></summary>

```powershell
# 只预装 small
powershell -ExecutionPolicy Bypass -File .\install-helper.ps1 -Models small

# 预装 tiny 和 base
powershell -ExecutionPolicy Bypass -File .\install-helper.ps1 -Models tiny,base

# 暂不下载模型，首次转写时再下载所选模型
powershell -ExecutionPolicy Bypass -File .\install-helper.ps1 -SkipModelDownload
```

</details>

电脑中安装了多个 Python 时，`-PythonExe` 后需要填写实际 `python.exe` 的完整路径。下面只展示填写方式，不包含任何真实本机路径：

```powershell
powershell -ExecutionPolicy Bypass -File .\install-helper.ps1 -PythonExe "<请替换为你的 python.exe 完整路径>"
```

> [!NOTE]
> 请把引号中的占位文字替换成你电脑上兼容版本的 `python.exe` 完整路径，不要只填写它的上级文件夹。

安装脚本会自动：

1. 创建独立的 Python 运行环境；
2. 安装本机 Whisper 和公开视频音频处理所需的依赖；
3. 下载并实际加载验证所选模型；
4. 生成本机随机令牌，无需手工填写或复制；
5. 注册为当前 Windows 用户登录后静默启动；
6. 启动并检查本机助手是否可用。

安装完成后，请回到 Chrome / Edge 扩展管理页，点击“重新加载”。

依赖默认从 PyPI 获取；如果连接失败，安装脚本会自动使用阿里云 PyPI 公共镜像重试。Whisper 模型从 ModelScope 的 Systran 镜像下载。上述服务只用于下载依赖或模型，不参与字幕转写。

## 🪄 怎么使用

1. 打开一个普通 B 站视频页。
2. 在右侧面板选择“当前分集”“本视频全部分P”“选择分P批量导出”或“整个合集”。
3. 扩展会先扫描 B 站字幕，并将结果分为：
   - **B 站字幕可用**：可以直接导出；
   - **需要本机补齐**：没有字幕、字幕为空或字幕明显错配；
   - **暂不可处理**：需要登录、无权访问、网络或接口失败。
4. 如果存在需要补齐的分P，可以选择 Whisper 模型并点击“免费本机补齐”；不想补齐时，选择“仅导出B站字幕”即可。
5. 处理完成后，点击“下载 Markdown”。

处理失败的分P会单独列出 P号、标题和失败原因。点击失败项可以打开对应视频，也可以点击“只重试失败项”，无需重新扫描已经成功的内容。

Markdown 会注明每集字幕的来源：B 站人工字幕、B 站 AI 字幕，或实际使用的本机 Whisper 模型。

## 🔒 隐私与安全

- 不使用付费 API、订阅服务、API 密钥或云端 AI 转写；字幕识别计算在本机完成。
- 首次安装、下载模型和获取公开视频音频仍需联网，但音频不会上传到 AI 服务。
- 扩展不会查看、复制或导出 Cookie 内容；访问 B 站官方接口时，浏览器可能自动携带当前登录状态。
- 本机 Whisper 助手不会提取浏览器 Cookie，也不会绕过登录、付费或地区限制。
- 本机助手只监听 `127.0.0.1:17891`，并使用随机安装令牌验证连接。
- 每次只处理一个分P；转写结束后会立即删除临时音频，任务数据和字幕缓存保存在本机。

## 🧰 遇到问题时

- **提示助手没装好、令牌缺失或无法连接**：重新运行 `install-helper.ps1`，然后到扩展管理页点击“重新加载”。
- **Python 版本不兼容**：确认使用的是 64 位 Python 3.10–3.12；安装多个版本时，用 `-PythonExe` 指向兼容版本的实际 `python.exe`。
- **模型下载失败**：检查网络和磁盘空间后重试。完整文件会直接复用，未完成的下载支持继续下载。
- **助手版本过旧或不支持所选模型**：重新运行 `install-helper.ps1`，然后重新加载扩展。
- **公开音频下载失败**：B 站或 `yt-dlp` 的解析方式可能发生变化，请更新项目版本后重试。
- **CPU 转写较慢**：这是正常的本机计算，可以让助手在后台继续运行，稍后回到同一个视频页查看进度。
- **提示需要登录或没有权限**：先在网页中确认自己可以正常观看该视频，然后刷新页面。此类视频不会自动进入 Whisper 队列。

## 🧹 卸载本机助手

不再需要 Whisper 时，在扩展文件夹中运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall-helper.ps1
```

卸载脚本会移除本机助手、模型、任务、缓存、启动项和本机助手令牌，但不会删除整个扩展文件夹。完成后请重新加载扩展。

## ⚠️ 使用边界

本项目仅用于个人学习，以及你自己有权访问的内容。不支持番剧、付费课堂、收藏夹或频道，不下载视频画面，也不绕过任何访问限制。使用 Whisper 时只会临时下载公开普通视频的音频，并在处理后删除。批量处理前请确认自己拥有相应权限，并遵守版权要求和 Bilibili 用户协议。
